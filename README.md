## About me

I've been building production web apps for 2+ years. At **AGSuite Technologies** I work across the stack: React and Next.js on the front end, Express APIs on PostgreSQL and MongoDB on the back end, and Docker to run it all.

Some of the things I've shipped there:

- An internal platform that replaced a manual record-creation process for **2000+ clients**, taking vendor onboarding from about 4 minutes to 1
- **50+ REST APIs** with validation, server-side pagination and proper error handling
- JWT auth with refresh-token rotation and role-based access control
- Document extraction with the OpenAI API, using structured outputs and retries for bad responses. It cut manual processing time by **60%**.
- LLM middleware with rate limiting and retry logic, plus NetSuite RESTlets and Suitelets for the same flow

Lately I'm most interested in LLM workflows that behave well in production: validated structured output, sensible retries, and LangGraph flows that are easy to reason about.
